Snooker Money Match – Version 5 OFFLINE

Alle Funktionen der korrigierten v4 bleiben erhalten.

Neu:
- Die komplette App wird nach dem ersten erfolgreichen Online-Start lokal auf dem Gerät gespeichert.
- Danach kann sie ohne WLAN und ohne Mobilfunk gestartet und benutzt werden.
- Bei bestehender Internetverbindung wird weiterhin die aktuelle Netlify-Version verwendet.
- Fällt die Verbindung aus, wird automatisch die lokal gespeicherte Version geladen.
- Matchdaten, Match-Historie, kumulierte Abrechnung und Zahlungen bleiben wie bisher lokal gespeichert.
- Ein Status in der App zeigt an, ob sie online oder offline läuft.

Installation auf iPhone:
1. Neue Version bei Netlify deployen.
2. Netlify-Adresse in Safari öffnen und vollständig laden lassen.
3. Safari: Teilen > Zum Home-Bildschirm.
4. App über das neue Symbol einmal bei bestehender Internetverbindung öffnen.
5. Danach zum Test Flugmodus einschalten und die App erneut über das Home-Bildschirm-Symbol öffnen.

Wichtig:
Nach einem späteren Update bei Netlify die App einmal mit Internet öffnen, damit die neue Version lokal übernommen werden kann.
