Snooker Money Match v6.0 – Firebase Live-Synchronisierung

Nach Anmeldung auf beiden Geräten werden Änderungen am Spielstand automatisch via Firestore übertragen. Lokale Speicherung und JSON-Dateien bleiben erhalten. Beim ersten Anmelden wird eine vorhandene Cloud-Sicherung als Ausgangsstand geladen. Bitte vor dem ersten Test auf dem zweiten Gerät den aktuellen Stand auf dem ersten Gerät in der Cloud sichern.

Hinweis: Live-Synchronisierung benötigt eine Internetverbindung. Gleichzeitige Eingaben auf beiden Geräten vermeiden.
